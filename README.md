# content-studio-kit

An agentic content studio for [Claude Code](https://claude.com/claude-code). It gives one main session a small crew of pinned agents, a set of video and caption skills, a plain-file memory system and a hook that retries failed agents on a stronger setting. It is built for video, social posts and homeschool lessons, and it keeps a human approval gate in front of anything that publishes or costs money.

This repository holds the **system only**: no videos, footage, narration, scripts, brand assets or channel content.

## What is inside

| Path | What it is |
|---|---|
| `CLAUDE.md` | The 28-line rulebook Claude Code reads first. It imports the memory index. |
| `.claude/agents/` | 19 agents, each with a `-xhigh` escalation twin (38 files). |
| `.claude/skills/` | 9 skills: `film-taste`, `motion-craft`, `brand-motion`, `ui-motion`, `story-reel`, `captions`, `footage-sourcing`, `music-and-mix`, `video-qa`. |
| `.claude/hooks/` | `agent-router.py` (escalation) and `memory-nudge.py` (memory reminders). |
| `.claude/settings.json` | Wires both hooks into Claude Code. |
| `memory/` | `MEMORY.md` index plus 26 one-rule memory files. |
| `tools/` | `pin_agents.py` (pin model and effort, generate twins) and `memory_index.py` (rebuild the index). |
| `licenses/` | Licence texts for two MIT projects that the `motion-craft` references were adapted from. |

## Model routing

The main session is the supervisor. It briefs **one agent at a time**, checks what comes back and reports to you. Every agent file pins both `model:` and `effort:` in its frontmatter, so nothing depends on a default.

- **Opus, high** for film and judgement work: `motion-director`, `motion-designer`, `video-editor`, `creative-director`, `script-director`, `qa-reviewer`.
- **Sonnet, high** for everything routine: captions, subtitles, file moves, lookups, renders, SEO text, homeschool agents.
- Never above `xhigh`, never a model other than Opus or Sonnet, and never `xhigh` by default. The router blocks anything outside that cap unless you set `KIT_ALLOW_ABOVE=1`.
- Parallel agents are off by default. Set `KIT_PARALLEL=1` to allow them.

Check the pins at any time:

```bash
python3 tools/pin_agents.py .claude/agents --verify
```

## Escalation

`.claude/hooks/agent-router.py` runs on `PreToolUse`, `PostToolUse` and `PostToolUseFailure` for the Agent tool. Each agent brief gets a closing request: `STATUS: DONE` or `STATUS: FAILED: <part>`. When an agent fails, only the failed part is retried:

```
Sonnet agent:  Sonnet high -> Sonnet xhigh (twin) -> Opus -> main session does it
Opus agent:    Opus high   -> Opus xhigh (twin)   -> main session does it
```

The `-xhigh` twin is the same agent with `effort: xhigh`. Twins are generated by `tools/pin_agents.py`, so never edit them by hand. Router state and a one-line-per-decision log live in `.claude/state/` (git-ignored). A success resets the agent. Paid tools are never retried automatically.

## Memory system

Memory is plain Markdown in `memory/`: **one file per rule**, plus an index.

1. `CLAUDE.md` imports `memory/MEMORY.md`, so every session starts by reading the index.
2. The index has one line per memory file: `- [Label](file.md): one-line summary`. The session opens only the file it needs.
3. When you correct Claude or say "save this to memory", it writes one new file (frontmatter `name`, `label`, `date`, `source`, then the rule, the reason and any exception) and adds one index line. If the rule replaces an older one, it updates that file instead.
4. The `memory-nudge` hook watches your prompts for corrections or "remember this" phrases and reminds the session to do the above.
5. Rebuild the index from the files at any time:

```bash
python3 tools/memory_index.py memory
```

The 26 files shipped here are working examples of house rules: approvals, paid actions, licensing, captions, pacing, escalation and so on. Rewrite them for your own studio. Files such as `channels.md` are templates with placeholder channels.

## Install

You need Claude Code, Python 3.10+, FFmpeg and Node 18+ (only for the `captions` and `ui-motion` scripts).

```bash
git clone https://github.com/Kapu25/content-studio-kit.git
cd content-studio-kit

# optional: install the Node helpers used by two skills
(cd .claude/skills/captions/scripts && npm install)
(cd .claude/skills/ui-motion/scripts && npm install)

# confirm every agent is pinned and every twin exists
python3 tools/pin_agents.py .claude/agents --verify
```

Open the folder in Claude Code. It reads `CLAUDE.md`, loads the agents, skills and hooks from `.claude/`, and the memory index comes with it.

## Use

- Ask for a job in plain words ("make a 60-second explainer from this script"). The main session picks the agents and briefs them one at a time.
- To add or change an agent, edit its file, then run `python3 tools/pin_agents.py .claude/agents --apply` to re-pin it and regenerate its twin.
- To add a rule, tell Claude "save this to memory" and let it write the file and index line.
- Create your own `channels/` (style guides), `workflows/` (run orders), `brand/` and `projects/` folders. The agents expect them but this repository does not ship them. `projects/`, `brand/logo/` and your private notes are in `.gitignore`.

## Built-in guardrails

Nothing is published, uploaded, scheduled or paid for without your explicit yes. Output stays `DRAFT-NOT-APPROVED` until you say the literal word "Approved". Footage needs a licence record in `sources.json`, and video downloaders are not used.
