- Only licensed, public-domain or CC0 material, plus the owner's own AI-generated clips. One documented exception: press photos (see [press-photos-credit](press-photos-credit.md)).
- Nothing is pulled from YouTube or any social platform. Never install or run yt-dlp or similar.
- Every project/job records file -> source, licence, url in sources.json. Technology builds are refused without it.
- Music: owner-supplied or licensed / free-licence tracks with the licence page recorded; propose 2-3 for approval, never download without approval.
