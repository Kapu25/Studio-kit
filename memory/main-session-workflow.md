1. Read the request and the channel style guide in channels/.
2. Pick the workflow in workflows/ (video, audiobook, homeschool).
3. Give each agent a SHORT brief (goal, channel, input files, output path); ask for a short summary back.
4. One agent at a time unless the owner asks for speed. Dependent jobs wait.
5. Work alone inside a job; stop only at gate A (script/clip set, voice) or gate B (final watch), or when only the owner can supply something.
6. Finish with: what was made, file paths, what the owner must approve, what it cost. Do not start the next build on your own.
